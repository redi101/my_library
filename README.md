# 📚 My Library

Учебный проект на **FastAPI** — асинхронный REST API для управления библиотекой книг, построенный на современном стеке Python.

## 🛠 Используемые технологии

- **Python 3.14**
- **FastAPI** — высокопроизводительный веб-фреймворк для создания API
- **SQLAlchemy 2.0** — ORM для работы с базой данных
- **SQLite + aiosqlite** — лёгкая асинхронная база данных
- **Pydantic v2** — валидация данных и описание схем
- **Docker и Docker Compose** — контейнеризация и быстрый запуск проекта

## 📌 Возможности

- Добавление новых книг в базу данных
- Получение списка книг с пагинацией через `offset` и `limit`
- Поиск книг по:
  - ID
  - названию
  - автору
- Обновление данных существующих книг
- Удаление книг из библиотеки

## 🚀 Запуск проекта

Самый простой способ запустить проект — использовать Docker. Устанавливать Python и зависимости вручную не потребуется.

### 1. Установите Docker

Убедитесь, что на компьютере установлен и запущен **Docker Desktop**.

### 2. Клонируйте репозиторий

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd my_library
```

### 3. Запустите проект

```bash
docker compose up --build
```

После запуска API будет доступно по адресу:

```text
http://127.0.0.1:8000
```
